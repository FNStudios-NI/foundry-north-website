## Goal
When done:
1. `tools/send_site.py` copies only `desks/site/public/` to the site's own repository and pushes it: it clones the repository (default `https://github.com/FNStudios-NI/foundry-north-site.git`, or `--repo <url or path>`) into a scratch folder, makes that clone's tree exactly the files git tracks under `desks/site/public/` at this checkout's `HEAD` (those files at the clone's top, nothing else, files gone from `public/` removed), commits with a message naming this project's commit, and pushes its `main`. It prints `SENT: <site commit> from <project commit>` and exits 0; with nothing changed it prints `NOTHING TO SEND` and exits 0.
2. It refuses, printing `REFUSE: <why>`, exiting 1 and pushing nothing, if anything outside that folder would cross: a file in the staged clone that is not a tracked file of `desks/site/public/`, a symbolic link, or uncommitted changes under `desks/site/public/` (what crosses is what git holds, never what sits on disk).
3. `--dry-run` says what would cross and pushes nothing.
4. `desks/site/docs/contract.md` § What it hands the rest says so: `desks/site/public/` is the site, the only part of this project that may be public; `tools/send_site.py` is the only way it crosses to `foundry-north-site`, which Cloudflare publishes.
5. Python 3 standard library and git only. A comment head in the tool's own style (what it is for, why, how to run it), as the other tools in `tools/` have.
Must merge first: none. Inputs: `docs/brief.md` § Design (where the site's files live) at main `1ea362c`.

## Gate — run it; done means this passes
`python -B -m pytest tools/tests/test_send_site.py -q` → `<n> passed`, with n ≥ 6, every test using local bare repositories under pytest's `tmp_path` as the remote (never the real one): a send of a small public folder (the remote's tree equals it); a second send with nothing changed (`NOTHING TO SEND`); a file removed from `public/` is removed from the remote; a refusal on uncommitted changes under `public/`; a refusal on a symbolic link (skipped where the system cannot make one, and said so); `--dry-run` pushes nothing. Each refusal test also checks the remote is unchanged.
Ablation: make the tool copy the whole checkout instead of `desks/site/public/` and the tree-equals test fails: at least 1.
Forbidden: any push to `https://github.com/FNStudios-NI/foundry-north-site.git` or any remote other than a test's own bare repository (refusal 5: the real first send is the master's, after landing); a change outside Touches; a secret.
