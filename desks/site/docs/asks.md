# Asks — site

The mailbox between the master and this desk: the one file both may write to. Add entries at the bottom; never edit an old one.
Copy the form in the project's `docs/blanks/asks-entry.md`.
An order is written here before any message says "look". Why: messages vanish, and this file is what survives.
Findings go up, never sideways: a problem in another desk is written here for the master, never fixed by this desk.
Each era starts a fresh asks file. Why: asks files that were never restarted grew to 127–222 KB.
