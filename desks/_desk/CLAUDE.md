# <desk> — for agents

This folder is one desk: a project in its own right, focused on one job, taking its orders from the project's master.
This is the starter. A new desk is a copy of this folder inside `desks/`, renamed in lowercase with hyphens.
Read the project's `CLAUDE.md` (two folders up) first. Nothing here repeats it.
Orders arrive in `docs/asks.md`. It is the one file the master and this desk both write to.
Never cross `docs/contract.md`. It is what this desk hands the rest; changing it is an ask to the master, not an experiment.
This desk plans its own builds and writes its own cards. The master sends the tasks and the aim, never the cards.
Stay inside this folder. A problem somewhere else is one Parked line, never a fix.
