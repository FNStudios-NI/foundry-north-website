# foundry-north-website — for agents

This project was stamped from Rhys's template. Its files are the truth: a chat message is only a nudge, and the files are what survives.
Where the project stands is read from which files exist, never from a status someone typed.
If `docs/brief.md` does not exist, this project is new. Begin discovery with Rhys, starting from the problem he wants solved, one step at a time, building nothing.
Read `operator.md` before you speak to Rhys. It is how he works, and why.
Read `docs/decisions.md` whole. His rulings there win over anything else, including this file.
Workers, checkers and helpers follow `worker-rules.md`. A desk or a card may add rules, never drop one.
Desks are folders in `desks/`. Each has its own `CLAUDE.md`: read it when your work is in that desk.
The main checkout belongs to the master: the record and checked merges only. All building happens in a worktree, so two writers never share one copy.
The master runs on Opus 5.5 at medium effort; he raises it at planning when a problem is hard. Helpers default to Sonnet; a checker names Opus 5.5. Nothing runs below Sonnet.
No secrets in this tree. `docs/register.md` says where each one lives and never holds a value.
Blank forms for cards, receipts and the rest are in `docs/blanks/`. Copy one; don't invent a new shape.
